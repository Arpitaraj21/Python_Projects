1. Create a virtual environment
python3 -m venv venv


2. Activate the virtual environment
.\venv\Scripts\Activate.ps1


3. Verify activation

Your terminal should look like this:
(venv) PS C:\Users\singh\Desktop\Python Projects\Python_Projects>


4. Check Python version inside the environment
python --version


5. Run your Python file
python dice_rolling_game.py


Remember:
- python3 --version → Checks Python installation.
- python3 → Opens Python interactive mode.
- python3 -m venv venv → Creates a virtual environment.
- Activate.ps1 → Activates the environment.
- deactivate → Exits the environment.
